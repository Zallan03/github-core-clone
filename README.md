A GitHub-compatible git forge in TypeScript (Node 22, stdlib only): git smart HTTP (protocol v0 and v2, upload-pack and receive-pack with shallow/deepen and annotated tags), the REST v3 API (repos, contents, issues, labels, pull requests with squash merge), GraphQL (repository, issues, pull requests, mutations, introspection), and MCP (JSON-RPC tools over Streamable HTTP) — all served from one in-memory store, plus the make.fun environment lifecycle.

## Run it

```sh
node --experimental-strip-types main.ts
```
